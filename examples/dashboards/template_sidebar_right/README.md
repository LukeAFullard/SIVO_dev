# Sidebar Right Layout Template

This example demonstrates how to use the `sidebar_right` dashboard HTML template.

The `sidebar_right` template creates a two-column layout where the smaller sidebar is positioned on the right side of the screen, and the main content area is on the left.

### Key Features Used:
- `SivoDashboard(template="sidebar_right")`: Loads the right-sidebar layout.
- `slot="sidebar"`: Places interaction panels in the right sidebar.
- `slot="main"`: Places the primary SIVO block in the larger left area.
