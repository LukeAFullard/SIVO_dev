# Dark Grid Dashboard Example

This example demonstrates how to build a high-contrast, dark-mode dashboard using the `dark_grid.html` template.
It creates a sleek, modern UI suitable for Operations Centers, live system monitoring, or technical readouts, using
ECharts' dark theme support and a custom 4-column CSS Grid.

## Key Features Demonstrated

- Using the dark-themed dashboard template (`template="dark_grid"`).
- Using ECharts dark theme for the map.
- Controlling 4-column layout spanning with `col_span`.

## How to run

Ensure you have SIVO installed, then run:

```bash
python main.py
```

Open `output.html` in your browser.
