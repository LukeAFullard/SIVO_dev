Python Workspace: This tab provides a fully functional Python IDE running entirely in your browser using Pyodide (WebAssembly). Write custom Python scripts using the `sivo` library to generate highly complex mapping applications. App Builder: This is a powerful No-Code visual editor for building SIVO applications. Start by selecting a pre-built template or your custom SVG, upload a dataset, and use the Property Inspector on the right to configure colors, tooltips, graphs, data bindings, and layouts without writing a single line of code. Equivalent Python code is automatically generated and sent to the Python Workspace.
