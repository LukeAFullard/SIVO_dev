# Infographic Navigation Menu Example

This example demonstrates how to use the `navigation_menu` and `navigation_menu_position` configuration options on a standalone SIVO Infographic.

When you run this script, it will generate an interactive HTML map containing a hamburger menu in the top left corner. This menu contains links to an external URL and a drill-through internal view.

## Files

- `infographic_nav.py`: The python script that generates the infographic.

## Usage

```bash
python infographic_nav.py
```
Then open `infographic_nav.html` in your browser.
