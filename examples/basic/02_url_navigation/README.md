# URL Navigation

This example demonstrates how to make elements in your SVG interactive links that open an external web page.

Key features shown:
- Loading an SVG (`Sivo.from_svg(svg_path, layout_size="99%")`)
- Mapping interactions to an external URL using the `url` parameter in `sivo_app.map(...)`
- Tooltips that provide context for the user when hovering over an element
