# Animations & Markers

This example demonstrates how to apply animation effects to elements and how to dynamically overlay markers aligned with SVG objects.

Key features shown:
- Applying looping visual animations (e.g. `pulse`, `fade`) to mapped elements
- Emplacing marker symbols on top of defined targets using `sivo_app.add_marker(...)`
- Offsetting markers natively with `offset_y` so they accurately reflect their map counterparts
