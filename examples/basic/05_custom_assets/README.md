# Custom Assets

This example demonstrates how to inject custom CSS and JavaScript into the interactive HTML exported by SIVO.

Key features shown:
- Injecting custom CSS classes into the interactive app (`custom_css` argument in `sivo_app.to_html()`)
- Referencing custom CSS classes in HTML popups (`class='custom-tooltip'`)
- Injecting custom JavaScript into the exported HTML application (`custom_js` argument in `sivo_app.to_html()`)
