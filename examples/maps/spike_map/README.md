# Spike Map Example

This example demonstrates how to create a spike map (a 3D-like map showing density representations, such as COVID-19 cases) using `Sivo.from_geodataframe()` and `app.apply_spike_map()`.

It uses a synthetic `GeoDataFrame` containing polygon grids and applies a choropleth for base styling, followed by adding a spike representation. Spikes use explicit centroid coordinates calculated dynamically via `shapely` geometries.

## Key Concepts
- Using `Sivo.from_geodataframe()` with a `geopandas.GeoDataFrame`.
- Dynamically deriving centroids from `GeoDataFrame` geometry to position items in Sivo.
- Applying a spike map via `app.apply_spike_map()` over an SVG representation generated by Sivo.

## How to run

```bash
PYTHONPATH=src python3 examples/maps/spike_map/spike_map.py
```
This will output a `spike_map.html` file in the same directory.
