# Global Economy Infographic

This example demonstrates how to create a professional, newspaper-style financial infographic using Sivo. It combines a static vector base (styled like a Financial Times or Bloomberg article) with dynamic, interactive Sivo mapping elements to visualize semiconductor supply chain flows.

## What it shows:

1.  **Professional Theming:**
    *   Demonstrates how to use a static SVG background as the base layer, creating an A4 report style look with traditional typography (`Times New Roman`, `Helvetica Neue`), drop shadows on map nodes, and a warm ivory background.
    *   Custom CSS is injected into the generated `Sivo` instance to apply a "Financial Paper Panel Styling" theme to the right-side information panel.

2.  **Mapping Interactivity with HTML Tooltips:**
    *   The `sivo_app.map()` function maps interactive behaviors to the static SVG circles (representing North America, Europe, and APAC).
    *   It uses rich HTML content within the mapping (`html="""<h3>...</h3><p>...</p>"""`) to present stylized statistical information in the side panel when these nodes are clicked.
    *   Hover tooltips and glow effects (`hover_color`, `glow=True`) are added for visual feedback.

3.  **Interactive ECharts Injection:**
    *   A static placeholder rectangle (`id="chart_investment"`) is embedded within the SVG file.
    *   An interactive ECharts bar chart ("Global CapEx") is mapped directly over this placeholder using the `echarts_option` argument in `sivo_app.map()`, seamlessly blending the native SVG with interactive Apache ECharts visualizations.

4.  **Dynamic Flow Connections:**
    *   Animated connection lines are added using `sivo_app.add_connection()`.
    *   These connections feature flow effects (`flow_effect=True`) mimicking trade routes with traveling symbols (`effect_symbol='arrow'` or `'circle'`). The paths trace over static dashed paths defined in the base SVG to enhance the feeling of moving data/goods.

5.  **Panel Configuration:**
    *   Crucially, `default_panel_position="right"` is passed into `Sivo.from_string()` so that the side information panel is visible and ready to display the rich HTML and chart payloads generated by the map interactions.

## Running the Example

From the root repository directory, run:

```bash
PYTHONPATH=src python examples/infographics/news_infographic_economy/main.py
```

This will generate an `economy_a4.html` file in the same directory, which you can open in a web browser to view the interactive infographic.
