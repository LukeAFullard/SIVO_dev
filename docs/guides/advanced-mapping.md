# H-14: Advanced Mapping Guide Plan

Guide on advanced thematic mapping: choropleths, hexbins, dot density, and flow maps.

## Table of Contents

1. **Introduction to Thematic Mapping**
   - Overview of data-driven styling for SVGs.
2. **Choropleth Maps**
   - Using `apply_choropleth()` for coloring based on values.
3. **Hexbin & Dot Density**
   - Clustering data with `apply_hexbin()`.
   - Distributing quantities visually with `apply_dot_density()`.
4. **Proportional Symbols & Flow Maps**
   - Sizing elements based on data using `apply_proportional_symbols()`.
   - Drawing connections with `apply_flow_map()` and `add_connection()`.
5. **Other Mapping Features**
   - Spike maps (`apply_spike_map()`), Value by Alpha (`apply_value_by_alpha()`).
