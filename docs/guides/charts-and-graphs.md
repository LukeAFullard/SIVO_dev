# H-13: Charts and Graphs Guide Plan

Guide on embedding native ECharts (bar, line, pie, scatter, etc.) into SIVO maps.

## Table of Contents

1. **Introduction to ECharts Integration**
   - Overview of SIVO's seamless ECharts embedding (`map_bar_chart`, `map_pie_chart`, etc.).
2. **Basic Charts**
   - Bar, Line, Pie, and Scatter charts examples.
3. **Advanced Charts**
   - Radar, Sunburst, Sankey, Funnel, and Heatmap charts.
   - Using configurations like `universal_transition`.
4. **Customizing Charts**
   - Styling options (`tooltip_bg_color`, `axis_color`, etc.).
5. **Interactive Data Zooming**
   - Enabling and using `datazoom=True`.
